# 登录页真实医疗背景调研与设计建议

日期：2026-10-04\
状态：初始调研记录；用户随后确认浅色衔接，正式页面已于本日实施更淡的渐变与连续轮换，见 [轮换验收记录](../design-review/2026-10-04-登录页渐变轮播验收.md)\
范围：登录页左侧视觉区及与之关联的表单样式。沿用已确定的青绿色主题、中文界面与微软雅黑字体。

## 推荐方向

选择真实拍摄的眼底影像采集或 OCT 检查场景，尽量让医护、成年患者、设备同时进入画面。照片表达检查过程中的照护关系；设备和屏幕提供眼科专业辨识度。

优先布局为：左侧品牌 → 完整横幅检查照片 → 浅鼠尾草绿背景中的简短说明；右侧维持白色登录表单。照片底部用透明度渐变衔接背景。这里的渐变只处理照片与背景的接缝，不把整张照片染成青绿色。

这一选择依据系统的实际主题与现有页面比例作出，不是“某一种颜色能提升医疗信任”的研究结论。CUH 的门诊说明将眼底照片、OCT、医生复核及后续处置联系起来，为照片题材与系统工作流程的对应关系提供依据。

来源：[CUH：OCT 与眼底摄影门诊](https://www.cuh.nhs.uk/patient-information/optical-coherence-tomography-oct-and-photography-clinic-with-virtual-review/)。

## 当前页面的具体限制

当前登录页位于 `src/views/login/index.vue`，左右比例为 `1.08fr : 1fr`，左侧至少占满一屏高度。现有左栏包含品牌、大标题、说明、RetinaArt 插画、流程文字与页脚，适合简单色块背景。

实景照片加入后，原有大插画和全部文字会与人物、设备竞争视觉注意力。应移除登录页的大眼睛插画，调整标题位置与字号，精简副文案；不能只替换背景声明而保留原来的全部构图。

多数医护与患者同框的检查照片为 3:2 横幅。以约 740×976 的左栏为例，整幅 `cover` 会保留约 51% 的原图宽度，人物位于两侧时容易被截断。使用接近原图比例的照片区域能保留检查关系。该限制已在独立预览中通过同一张图片的两种布局验证。

## 三种布局比较

| 布局 | 优点 | 局限 | 选择 |
| --- | --- | --- | --- |
| 横幅照片衔接浅鼠尾草绿文字区 | 保留医护、患者与设备；深色文字稳定易读；与现有轻柔主题一致 | 左栏不是从顶到底全部由照片填满 | 推荐 |
| 整幅照片加下方深青遮罩 | 左侧沉浸感强；白色品牌与标题突出 | 横图容易裁掉人物；深色区域更重；须按最终图片逐断点校对对比度 | 对照 |
| 竖幅实景照片铺满左栏 | 可以同时满足满栏照片和人物完整呈现 | 需要符合构图的原生竖幅照片，不能靠硬裁当前横图获得 | 找到合适照片后可采用 |

目前的选择是第一种。若最终必须整幅铺满，选图时就应要求竖幅或有充足边缘空间的接近方形画面。

## 组件如何一起调整

| 组件 | 具体建议 |
| --- | --- |
| 品牌区 | 保留“糖网诊疗”和副标题，标志维持青绿色，位于稳定的浅色区域；不压在人物脸部或设备屏幕上 |
| 标题 | 保留现有两行中文标题，桌面从最大 42px 调整至约 32–36px，字体为微软雅黑，字重 600；放在照片下方 |
| 说明文案 | 调整为“汇集眼底影像与临床信息，衔接医生复核与持续随访。”，字号 14–15px；多智能体共识的详细说明留在业务页面 |
| 大眼睛插画 | 从登录页移除；品牌眼形标志仍保留，实景照片承担主题表达 |
| 流程文字 | 简化为“影像采集 → 医生复核 → 持续随访”，12–13px，降低视觉权重 |
| 表单区域 | 保持近白底 #FEFEFE，宽约 370–400px，避免照片干扰输入与错误提示；无需额外浮层卡片 |
| 输入框 | 建议 46–48px 高、8px 圆角；边框保留 #81939A，焦点用主色及浅绿外圈；密码显示功能与校验逻辑保留 |
| 登录按钮 | 主色保留 #2D8075，悬停 #22665D；48px 高，与输入框统一圆角 |
| 演示账户说明 | 保留事实说明，使用浅灰 #F3F5F7 小面板，视觉权重低于表单 |
| 移动端 | 照片约 160–180px 高，保留人物脸部和主要设备；减少品牌区上下间距，收起副文案和流程；优先让登录按钮可见 |
| 图片加载失败 | 浅绿色底色、品牌和标题仍显示，图片不影响登录表单使用 |
| 字体与语言 | 所有界面文本继续使用“Microsoft YaHei / 微软雅黑”；不加入装饰性英文小标题，OCT 等医学缩写可以保留 |

推荐配色：主色 #2D8075；照片衔接背景 #E9F4F1；标题 #263238；正文 #4C5B63；次要说明 #606F79；表单底色 #FEFEFE。真实照片保留自然肤色，避免全图高强度蓝绿滤镜。

## 选图与素材落地条件

正式图片优先采用获得授权的真实眼科科室摄影，理想构图为医护、成年患者、OCT/眼底摄影设备同框，人物不过度摆拍；背景简洁，白灰与浅青色为主。图库可作为备用，但需逐张核对设备类型，不仅根据标题判断。

上线素材建议：1600–2000px 宽，WebP 优先，压缩后以约 200–450KB 为优化目标；目标大小应以清晰度为准。使用本地静态资源，声明图像尺寸或固定比例，避免依赖外部图库链接。照片中的第三方设备标识无需刻意放大，也不添加虚构疾病标签或检查结论。
