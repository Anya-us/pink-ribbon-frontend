## 共用数据与刷新

初始 fixture 包含 6 个患者、7 次检查、12 条影像记录、5 个草稿、2 个合成签发报告、14 个准备/随访任务、2 条审核记录、2 个机构和2个设备。

- 右眼和左眼分别保存图像引用、质控、候选等级和 DME 状态。未评估为 null / not_assessed，保持与 0 级或阴性分开。
- 正式随访必须关联同一患者、同一检查的已签发报告；准备清单另用 preparation 类型。
- 档案编辑、任务状态和采集元数据保存在浏览器。File、blob URL 与原始文件内容仅在当前会话存在，重新打开后须重选原图。
- 患者服务只读取对应 patientId 的已签发报告及其正式计划。未签发草稿、准备清单与其他患者报告不进入服务结果。
- 区域汇总从同一个检查/报告/任务仓库计算。本次初始状态为 6 人、7 次检查、3 次待审核、1 项待执行随访。
- 眼底预览使用明确标记的结构 SVG 示意；合成质控和候选等级来自 fixture，不能解释为此示意图的真实诊断。

字段与接口签名见 [DR 数据与服务约定](../dr-data-contract.md)。HTTP 调试接口只读初始 fixture；页面可写状态在浏览器服务统一管理，后续接入 API 应整体切换适配。
