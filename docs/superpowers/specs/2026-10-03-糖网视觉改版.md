# 糖网多模态诊疗前端视觉改版

状态：用户已确认视觉方向，按该方向实施。

## 已确认设计

柔雾青绿为主色（#2F6F6B），鼠尾草绿用于轻量填充，灰蓝（#476E89）承载辅助数据，背景为浅灰绿（#F4F7F6）。使用深色文字与清晰边界维持可读性。影像区域独立使用深色画布，不改变原始影像颜色。红色、琥珀色仅用于高优先级与待复核状态，不能用主色替代警示。

## 实施范围

1. 统一 Element UI、侧栏、导航、页签、登录页、品牌图形及浏览器标题。
2. 改造工作台、患者档案、多模态采集、共识评估、分级证据、处置随访、眼健康助手全部业务页面。
3. 清除可达页面的粉红丝带、乳腺癌、肿瘤亚型、虚构疗效及药物处方内容；旧首页入口指向新工作台。
4. 保留 Vue 2 / Element UI 现有架构与登录、导航功能。业务数据使用统一、明确标记的演示病例。
5. 左右眼分别呈现。DR 分级、DME 状态、工作流状态分别显示；未评估不当作正常。AI 内容为演示草稿，医生签发另行呈现，不伪造已签发结论。
6. 上传仅用于本次浏览器会话中的选择与预览，未连接上传/推理接口必须明确说明。刷新后不保留患者影像与身份信息；随访及问答交互同样说明演示边界。

## 实施顺序

设计变量与公共界面 → 统一演示数据与组件 → 七个业务页面 → 清理旧主题入口 → 静态检查与生产构建 → 浏览器逐页检查、交互检查与移动端检查。

## 验收

- 主题变量集中定义，普通按钮无渐变，键盘焦点可见，页面可缩放。
- 所有业务页面无乳腺癌残留内容；导航、状态、图表遵循同一配色。
- 文件选择、字段验证、步骤切换、病例筛选、证据查看、任务记录、问答及打印操作可用，且没有误导性的后台成功提示。
- 新修改文件通过 ESLint；生产构建成功；桌面及移动视口无页面级横向溢出与浏览器运行错误。
- 保存改版后页面截图供用户核验。无需部署。
